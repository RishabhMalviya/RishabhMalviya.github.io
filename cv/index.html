Projects

  • BSP: Body Schema Pretraining — Sample-Efficient RL for Robotic Locomotion

    Stanford RL for Robotics, final project. Designed and experimentally validated a novel two-stage RL framework built on the insight that a robot’s body dynamics are task-agnostic and fixed: pre-train a body-dynamics model once, reward-free, then re-use it as the actor backbone for downstream tasks sharing the same body (stand / walk / run on the DeepMind Control Suite).

    • Synthesized techniques from 6+ research papers into a working system: an ICM-style curiosity-driven exploration loop (intrinsic reward = the dynamics model’s own next-state prediction error), a BERT/MLM-style masked-reconstruction objective over interleaved (state, action) token sequences (à la SGI), and SimNorm soft-simplex latents (DreamerV3 / TD-MPC2) for well-conditioned representations.
    • Built the DynamicsPredictor Transformer (DPT) — an encoder-only Transformer pre-trained via masked trajectory reconstruction, then fine-tuned as a PPO actor (action head + pooling) with a separate MLP critic on each downstream task.
    • Validated the core hypothesis: under identical fine-tuning hyperparameters, the pre-trained DPT actor consistently reached higher reward, faster, than a randomly initialized actor on walker-stand.
    • Diagnosed and solved subtle RL failure modes: jerk + entropy regularization to stop the exploration agent from gaming the intrinsic reward with high-frequency oscillations, Welford running observation normalization, variable-length history sampling biased toward long windows, and dead-end truncation to keep the replay buffer clean.
    • Surfaced a non-obvious finding: the non-stationary intrinsic reward destabilized DDPG’s off-policy updates, while PPO’s stochastic trust-region updates remained stable — informing the choice of PPO end-to-end.
    • Engineered a complete experiment-orchestration stack: config-driven runs, Makefile + detached tmux session management for long training jobs, wandb experiment & artifact tracking, smoke tests (fine-tuning, config, eval-video pipelines), and uv-managed reproducible environments.
  • CFD-MLOps — Distributed Training of a Surrogate CFD Model for Vehicle Aerodynamics

    Trained a neural PDE surrogate that predicts surface pressure and 3-component wall shear stress at every node of a car’s surface mesh in a single forward pass, replacing CFD solver runs that take hours-to-days per design.

    • Adapted the Transolver Transformer-based neural operator (physics-attention over irregular meshes) to the surface-only DrivAerML dataset — 500 high-fidelity OpenFOAM simulations of morphed DrivAer road-car geometries — mapping 7 geometric input channels (position, SDF, normals) to 4 predicted physical fields (pressure, shear stress).
    • Built the multi-GPU training stack with PyTorch DDP + torchrun to overcome Transolver’s activation-memory bottleneck on large mesh inputs; includes checkpoint/resume, single- vs multi-GPU parity testing, and a dataset smoke test asserting tensor shapes.
    • Engineered the data pipeline for large-scale 3D physical simulation data: VTK/.vtp mesh parsing, SDF and normal computation, and a caching layer to keep multi-GPU training free of I/O bottlenecks; environment reproducibility via uv and a Makefile.
  • Python ML REST API Deployment Template

    GitHub template project for packaging any ML model as a Dockerized FastAPI REST API, with zero-downtime rolling re-deployment via Traefik, identical Docker-based dev/prod environments, a docker-compose test + deploy CI/CD skeleton, and a PyTest suite; deploys to any Linux server with a single script. Written up in Create a Zero-Downtime Deployment of Your Machine Learning API (Better Programming).

  • Reinforcement Learning with Deep Q-Networks in PyTorch

    From-scratch PyTorch implementations of DQN, Double DQN, and Dueling DQN, behind a reusable agent / environment / hyperparameter abstraction with pluggable training-completion criteria. Trained and benchmarked on OpenAI Gym (LunarLander-v2, CartPole-v1) and a Unity ML-Agents environment (Banana Collector), with before/after rollout visualizations. 8 GitHub stars.

    ROS/catkin package exposing few-shot facial recognition (Siamese-network embeddings via dlib / face_recognition) as ROS services and nodes; supports face-encoding registration, static-image inference, and real-time recognition off a live sensor_msgs/Image stream published to a ROS topic. Robotics-stack integration in C++/CMake + Python.

    C++ Arduino library for building neuromorphic robot controllers: LIF spiking neurons accepting analog and asynchronous digital sensor input, composable into arbitrary network motifs following liquid-state-machine / reservoir-computing paradigms, with motor neurons wired directly to L293D drivers for actuation.
